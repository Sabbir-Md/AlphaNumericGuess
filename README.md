# AlphaNumeric Guess

## Description
AlphaNumeric Guess is a logic-based puzzle game where players must guess a hidden combination of letters and numbers within a limited number of attempts. After each guess, the game provides feedback to help players identify the correct characters and their positions. The game challenges logical thinking, pattern recognition, and problem-solving skills.

## Features
- Randomly generated alphanumeric secret code
- Limited number of guessing attempts
- Instant feedback after each guess
- Score tracking system
- User-friendly graphical interface
- Replay option for multiple rounds

## Technologies Used
- Python 3
- Tkinter (GUI)

## How to Play
1. Launch the game.
2. Enter your guess using the required combination of letters and numbers.
3. Submit your guess.
4. Analyze the feedback provided.
5. Continue guessing until you discover the secret code or run out of attempts.

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/AlphaNumeric-Guess.git
   ```

2. Navigate to the project folder:
   ```bash
   cd AlphaNumeric-Guess
   ```

3. Run the game:
   ```bash
   python main.py
   ```
